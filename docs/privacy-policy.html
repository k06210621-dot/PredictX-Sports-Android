PredictX Sports 隱私政策

本隱私政策說明 PredictX Sports（以下稱「本應用」）如何收集、使用、儲存及保護您的個人資料。使用本應用即表示您同意本政策的條款。

1. 我們收集的資訊

1.1 本應用不收集任何個人識別資訊：本應用不會收集您的姓名、電子郵件、IP 位址、裝置識別碼、位置、行蹤、生物特徵、通訊錄、相片、媒體或任何其他個人資料。

1.2 我們不讀取裝置資訊：本應用不收集裝置型號、系統版本、應用程式使用統計、不讀取 Advertising ID（廣告 ID）、不啟用任何追蹤 SDK。

2. 第三方服務

本應用僅與下列第三方服務互動，且互動均不涉及個人資料：

  • Google Play Billing — 由 Google Play 直接處理付款，所有帳款資訊由 Google 管理；本應用僅收到 Google 提供的產品 ID 與購買狀態（例如「標準版月度訂閱」），不接觸您的信用卡或付款紀錄。
  • TheSportsDB API — 本應用向 TheSportsDB 公開資料來源查詢運動賽事資料（例如隊伍名稱、比賽時間、球員數據），此類資料為公開賽事資訊，無個人識別資訊。
  • PredictX Sports 後端 API — 本應用向本專案自建後端（Railway 平台）查詢 AI 分析結果與賽事預測，僅傳輸 App 內 UI 顯示所需的賽事 ID 等公開識別碼，後端不會寫入或讀取任何裝置端識別資訊。

本應用 未整合 Firebase Analytics、Crashlytics、Facebook SDK、AppsFlyer、Adjust、任何廣告 SDK、任何追蹤 SDK、任何推播 SDK；不會發送任何推播通知；不會將您的資料用於個人化廣告。

3. 資料的儲存

本應用僅於您裝置本地儲存下列非個人狀態資訊：

  • 訂閱層級標記（Free / Basic / Standard，用於判斷您購買的方案）
  • 已解鎖的賽事分析 ID（用於避免重複扣點）
  • 主題偏好（深色／淺色模式）
  • 已收藏的賽事 ID 列表

上述資料僅儲存於您裝置的 App 私有目錄，未與任何伺服器同步。當您解除安裝本應用時，這些資料會自動一併刪除。

4. 兒童隱私

本應用定位為18 歲以上運動數據愛好者使用之娛樂工具。AI 預測僅供參考與分析，非博弈用途。我們不會刻意收集 18 歲以下兒童或青少年之資料。

5. 您的權利

由於本應用不收集您的個人資料，您無需申請存取、更正或刪除。如您希望清除本機所有狀態（訂閱標記、收藏等），可直接解除安裝本應用，本機資料將隨之完全清除。

6. AI 分析點數

AI 分析點數系統由本應用內部管理，僅用於控制賽事分析的存取次數。此點數無法兌換現金或其他等價物，亦不涉及任何金融帳號連結。

7. 政策變更

我們隨時可能修改本政策，重大變更將在下次更新版本透過應用內提示告知。繼續使用本應用即表示同意變更後的條款。
